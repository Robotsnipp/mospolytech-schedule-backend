# Планирование учебного расписания

## Термины

**Учебный план**: программа обучения определённого набора и формы обучения с распределением дисциплин и нагрузки по семестрам обучения.

**Семестровая нагрузка плана**: часы отдельной дисциплины в конкретном семестре обучения с видами занятий и формами контроля.

**Календарный семестр**: период конкретного учебного года, общий для участвующих групп.

**Модуль**: часть календарного семестра с заданными датами и количеством учебных недель.

**Локация**: адрес, где расположены один или несколько учебных корпусов.
_Не использовать как синоним_: кампус, площадка.

**Дополнительное место проведения**: место занятия вне сопоставленного справочника университетских помещений, например адрес партнёра. Такая категория сама по себе не подтверждает владельца здания.

**Лекционный поток**: группы, совместно посещающие одну лекцию.

**Занятие для планирования**: потребность в занятиях определённого типа для группы, потока или проекта.

**Проектная деятельность (ПД)**: занятия участников выбранного проекта; состав проекта может включать студентов разных учебных групп.

**Фиксированное занятие ПД**: уже назначенное занятие проекта с известным временем и местом, которое учитывается при размещении остальных занятий.

**Предложение физкультуры**: доступный вариант активности в определённое время и в определённых местах. Предложение ещё не означает запись студента на это занятие.

**Группа ДПО**: отдельная группа слушателей программы дополнительного профессионального образования.

**Персональное расписание**: занятия учебной группы и лекционных потоков студента вместе с занятиями выбранного им проекта.
