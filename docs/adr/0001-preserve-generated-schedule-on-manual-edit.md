# Сохранять ручные правки отдельным вариантом расписания

Ручные переносы и обмены пар сохраняются отдельным вариантом со связью с
исходным результатом генерации. Исходный результат остаётся неизменным и
доступным для возврата: замена его пар на месте лишила бы пользователя
возможности вернуться к результату решателя. Сохранение ручного варианта
не запускает генератор повторно; конкретная структура хранения ещё проектируется.
